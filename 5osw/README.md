# 5osw — 5o с исходным свайп-скроллом

Локальный маршрут: http://127.0.0.1:5190/5osw
Ветка разработки: `codex/v5osw`. База: опубликованная 5o `b7c8906`.

## Где код

5osw — самостоятельный маршрут в общем приложении `5o/prototype`.
Отдельная копия всех исходников не нужна: режим выбирается явными props,
поэтому GPU/particle исправления остаются общими. Корневой маршрут `/`
по-прежнему ведёт на `/5o`; сама 5o сохраняет нативный скролл.
`/5o-steps` оставлен контрольной версией без новых визуальных доработок.
Исходники коллег в `V5 Final Tuning` не меняются.

## Сохранено

- Остановка GPU-рендера невидимого кристалла, пробуждение при возвращении.
- Пропуск luminance/blur Bloom при нулевой интенсивности; прежний composite.
- Оптимизации проекций/буферов частиц и кэширование неизменного фона.
- Исходные число частиц, DPR, материалы и качество изображения.
- Кольцо автоплея карточек с общим timeout и отменой при ручном переключении.
- Центрирование активного пункта при resize; планшетная композиция hero,
  навигации карточек и подписей/кристалла в тезисах.

## Возвращено

Исходные GSAP-переходы, pinning, wheel/touch gesture handlers и поэкранные
свайпы. У 5osw нет `native-scroll-page`, дополнительных svh-треков,
нативного playhead, fixed crossfade-поверхностей и новой построчной заливки.
Появление/уход карточек, волна и переход к частицам используют исходную
свайп-хореографию. Её задержки и ограничения инерции не объявляются исправленными.
Native-only обход пружины и отказ от touch-drag кристалла не переносятся.

## Запуск и проверка

```sh
cd 5o/prototype
npm run dev -- --host 127.0.0.1 --port 5190 --strictPort
npm run test:rendering
npm run test:scroll
node --test tests/landing-gesture.test.mjs
npm run build
```

Сравнивать `/5osw` со `/5o-steps` для механики и `/5o` для нативного варианта.
Проверить прямой вход, карточки/кольцо, оба абзаца, грани, частицы, возврат,
планшетную композицию. Физический iPad Safari требует отдельной проверки.
На этом этапе пуш и деплой не выполнялись.

## Проверено 16 октября 2026

Production build, Bloom test, 2 native timeline tests (регрессия 5o),
3 landing-gesture tests и `git diff --check` проходят.
В Chrome `/5osw`: `nativeTracks = 0`, класс `swipe-scroll-page`,
`data-crystal-layer = 5o`, у world-model текста `background-image: none`.
DevTools подтвердил прежние непассивные window-обработчики: wheel 4,
touchmove 2. На карточках stroke-dashoffset кольца меняется по autoplay.
Пройдены карточки → первый → второй абзац, переход к тезисам и обратный
возврат к карточкам. Композиция первой грани осмотрена при 1024×1366 и
1024×768: подпись отделена от кристалла, ширина документа 1024 в portrait.
При смене размера активный pin может сдвинуть текущую сцену; после свежего
входа landscape-композиция корректна. Это не тест физического iPad и не
полный прогон всех particle-глав; прежние ограничения свайп-механики остаются.
